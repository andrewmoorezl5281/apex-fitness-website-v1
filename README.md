## Project Overview

Apex Fitness is a six-page website for presenting a gym and fitness brand through a clean, responsive-style interface. The project combines structured HTML pages with CSS styling, JavaScript behavior, and jQuery-powered interactions.

Alongside the core site content, the project demonstrates several useful website features: a timetable populated from JSON, a lightbox image gallery, and a membership registration form. Visitors can also calculate their BMI and receive a confirmation page after submitting the form.
